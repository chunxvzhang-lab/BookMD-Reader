# 欢迎

BookMD 阅读器是一个本地优先的 Markdown 书籍阅读器。它保留轻量 Markdown 查看器里实用的阅读体验，并为长篇书籍增加了持久书签跳转。

## 这个示例覆盖什么

- 根据书籍清单进行章节导航。
- 根据当前章节标题生成页内大纲。
- 渲染 GitHub 风格 Markdown。
- 在当前章节内搜索。
- 书签刷新后仍然保留，并能跳回保存位置。

## 键盘优先阅读

使用 `Alt + Left` 和 `Alt + Right` 在章节之间切换。使用 `Ctrl + B` 保存当前位置为书签。

## 用于滚动测试的长段落

书签会同时保存标题和滚动位置。也就是说，即使标题后来变化，跳转仍然可以尽量落在保存位置附近。

这段示例文本提供足够的高度，用来观察滚动恢复是否生效。一个好的阅读工具应该安静地把你带回正确段落，而不是让你重新在一整面文字里寻找。
