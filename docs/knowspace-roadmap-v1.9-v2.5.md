## 🚀 二、 近程里程碑：v1.9.0 —「Structure & Visualize · 结构认知与图谱深度增强」

> **目标**：突破一维纯文本线性局限，让文档结构即刻立体化，深化知识网络分析能力。

### 1. Markdown AST 实时双向思维导图 (Mind Map View)
- **多维度视图无缝切换**：在顶栏/右侧新增“思维导图”视图模式，将文档的 H1~H6 标题树以及重要要点实时编译为交互式思维导图。
- **双向联动聚焦**：
  - 点击思维导图节点，左侧编辑器/阅读区平滑滚动高亮到对应小节；
  - 在大纲折叠时思维导图节点同步折叠收缩；
- **结构化导出**：支持一键将当前思维导图导出为矢量 SVG、高分辨率 PNG 或 OPML 结构化大纲。

### 2. 知识网络图谱高阶分析与视觉增强
- **多阶邻居探索（Hop Filter）**：在图谱工具栏支持一键切换 `1-hop / 2-hop / 全局` 探索范围，专注阅读当前上下文强关联网络。
- **多维度自动着色系统（Color Palette）**：
  - 按文档所属文件夹/目录自动分配群组色彩；
  - 按文档主标签（`#Tag`）自动聚类染色；
- **核心枢纽与网络权重分析**：
  - 计算 PageRank / Degree Centrality，突出显示知识库中的“核心知识枢纽（MOC）”；
  - “知识孤岛”一键筛选与快速关联建议。
- **图谱高清快照**：支持当前视口图谱一键导出为矢量 SVG 与高清无损图片。

### 3. 块级原子引用与嵌入 (`[[doc#^block]]` & `![[doc]]`)
- **段落级/卡片级嵌入**：通过 `![[文档名称#章节]]` 或 `![[文档名称#^block-id]]` 将其他文档的段落、表格或数学公式以“卡片微预览”方式动态内嵌在当前正文中。
- **一次编写，处处复用**：修改原卡片内容，所有嵌入引用的文档自动呈现最新成果，实现原子化模块化笔记。

## 🎨 三、 中程里程碑：v2.0.0 —「Canvas & Command · 无限空间画布与全局命令中枢」

> **目标**：从单篇笔记跃迁至“多维思考平面”，打造无边界灵感白板与键盘盲操中心。

### 1. 无限空间可视化白板 (Infinite Canvas)
- **无界空间漫游**：基于 WebGL/Canvas 构建无限平移与缩放画板（兼容开放 `.canvas` 格式）。
- **多模态卡片自由混排**：
  - 自由拖放 Markdown 卡片、便签贴纸、PDF 截取小片、图片与代码块；
  - 双向链接连线（带方向箭头与关系标注），在空间中直观构建概念地图。
- **空间向图谱/文章逆向转化**：支持将画板上的逻辑连线与卡片一键萃取并归纳为一篇结构化 Markdown 专著。

### 2. 全能命令中心中枢 (Command Palette / `Ctrl + K`)
- **键盘驱动极速操作**：
  - 呼出快捷输入框，支持拼音首字母模糊匹配全部命令；
  - 最近访问文档（MRU）、快速在分屏中打开、切换白天/深色/护眼/水墨屏主题；
  - 一键执行重命名、添加双链、切换视图模式等高频操作。

### 3. 全库混合检索引擎 (Hybrid FTS5 + BM25)
- **毫秒级本地倒排索引**：借助 SQLite FTS5 / BM25 算法，在万篇文档库中实现即搜即显，精准定位至段落行。
- **多标签布尔组合过滤**：支持类似 `tag:#技术 AND link:[[系统设计]]` 的复合结构化过滤。

## 🌌 四、 进阶里程碑：v2.1.0 ~ v2.5.0 —「Knowledge OS · 本地智能体与多端安全生态」

> **目标**：打造隐私至上的个人专属智能协作者，实现全设备无缝衔接。

### 1. 本地优先 AI 知识协作者 (Local AI Co-pilot)
- **100% 离线隐私推理**：
  - 直连本地 Ollama / llama.cpp，支持 DeepSeek-R1、Qwen2.5 等开源大模型；
  - 纯本地 RAG（检索增强生成），知识库不上传任何第三方云端。
- **多模态智能服务**：
  - 自动归纳长文摘要、智能提取文章概念并主动建议建立 `[[双向链接]]`；
  - 基于知识图谱的跨文档概念问答（“根据我的笔记，XX 和 YY 的异同是什么？”）。
- **云端混合直连兜底**：允许配置用户自己的 Gemini API / Claude API Key，低算力轻薄本无缝享受顶级大模型推理。

### 2. 端到端加密安全同步 (E2EE Cloud Sync)
- **数据完全归属用户**：不设中心化私有服务器，支持标准开放存储协议：
  - WebDAV（坚果云、Nextcloud、群晖 NAS）；
  - S3 兼容对象存储（Cloudflare R2、MinIO、阿里云 OSS）；
- **客户端端到端零知识加密（Zero-Knowledge E2EE）**：AES-GCM-256 本地加密后再上传，云端仅见密文数据碎片，断网离线无损工作。

### 3. 插件拓展系统 (Plugin Extension SDK)
- **模块化插件机制**：提供基于 TypeScript 的轻量沙盒化插件接口。
- **典型生态插件**：
  - Zotero / 文献引用集成插件；
  - 自动化周报/日记模板生成器；
  - Excalidraw 手绘手写白板扩展。

## ⚡ 五、 底层常态化底座建设（绿色能耗与极限性能）

在功能迭代全流程中，持续贯彻已建立的极致性能工程规范：
1. **长文档虚拟化滚动**：万行超长专著 DOM 节点恒定 < 200 个，维持恒定 60 FPS。
2. **多标签页冷冻与瞬时注水（Tab Hydration）**：非激活标签页自动休眠释放 DOM，多开 30+ 标签页内存降低 70%+。
3. **AST 增量流式编译**：主线程与 Web Worker 读写分离，打字与候选框彻底零卡顿。
