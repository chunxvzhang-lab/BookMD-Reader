# KnowSpace v1.7.0 研发实施规划：空间视觉思考、思维导图、无限白板与混合检索

> **版本定位**：从「网状知识互联（Connect）」跃迁至「空间多维认知与视觉思考（Visualize & Know）」  
> **核心代号**：**Visualize & Know（空间视觉认知）**  
> **规划基线**：基于 KnowSpace `v1.5.1` 三主题极客编辑底座与 `v1.6.0` 双链全生命周期网络。  
> **制定时间**：2026-08-27  

---

## 🧭 一、 整体规划与设计愿景

在 `v1.6.0` 实现了双向链接全生命周期网络、反向链接面板、高保真专业 PDF 分页排版与闪念胶囊后，KnowSpace 已构建起坚固的知识互联骨架。

然而，**一维线性纯文本对于人类大脑的全局理解与发散思考具有天然局限**。当思考复杂系统、梳理宏观逻辑或进行头脑风暴时，知识创作者迫切需要空间化、拓扑化与视觉化的表达维度。

**KnowSpace v1.7.0 的核心使命是「开启空间视觉认知双引擎」**：
1. **结构化思维导图（Markdown AST Mind Map）**：从一维线性大纲跃升为二维树形脑图，支持**全键盘极客交互**与 **Markdown 源码双向实时无损回写**。
2. **本地优先无限空间白板（Infinite Canvas / Whiteboard）**：提供无边界二维画布，支持 Markdown 卡片、彩色便签、文档传送门、架构图与图片自由摆放，通过智能磁吸连线与语义标签建立空间关联网络。
3. **开放标准与本地优先**：白板采用开放透明的 `.canvas` JSON 格式原子落盘（与开源生态无缝兼容），思维导图零多余配置文件即开即用。
4. **双链网络与视觉全景深度交织**：脑图节点与白板卡片无缝解析 `[[双链]]` 与悬浮微光快照预览，双链拓扑可一键映射为白板关系图。
5. **本地离线混合语义检索与全能命令中心**：BM25 + 本地轻量 ONNX 向量混合检索，`Ctrl + K` 命令中心秒级调取一切。

## 📋 三、 模块详细拆解与工程实现方案

### 模块 1：结构化思维导图（Markdown AST Mind Map） 🟢 `[⚡ GPU/Canvas 渲染加速]`

#### 1. Markdown AST 与脑图树双向转换引擎 (`src/services/mindmap-ast.ts`)
- **数据结构定义**：
  ```typescript
  export interface MindMapNode {
    id: string;              // 稳定唯一哈希
    text: string;            // 节点标题文本（含行内 Markdown 语法）
    level: number;           // 标题深度 (1~6) 或列表嵌套层级
    sourceLine: number;      // 源码所在行号 (对应 AST data-source-line)
    children: MindMapNode[]; // 子节点数组
    isCollapsed?: boolean;   // 是否收起分支
    tags?: string[];         // 节点解析出的 #标签
    wikilinks?: string[];    // 节点解析出的 [[双链]] 引用列表
  }
  ```
- **双向增量 Diff 同步算法**：
  - **Markdown ➔ 脑图**：通过 AST 扫描 `heading` 节点与顶层 `list_item`，在 3ms 内生成层级严格对齐的树状结构。
  - **脑图 ➔ Markdown**：当用户在思维导图拖拽调序、重命名或新增分支时，算法比对节点间的层级与前后顺序差分，精准修改源文件对应的 Markdown 代码段并保持行号对齐，零格式损坏。

#### 2. 思维导图主交互视图 (`src/components/MindMapView.tsx`)
- 基于 HTML5 2D Canvas 与矢量 SVG 双渲染管线：
  - 分支贝塞尔曲线平滑绘制，依据当前主题色动态赋予柔和色谱渐变。
  - 节点微光选中框、展开/收起计数胶囊（如 `+5` 个子主题）。
  - 支持左右对称经典布局（Left-Right Balanced）、单向向右逻辑树（Right Tree）、向下组织架构图（Org Tree）。
- **三主题视觉体系**：
  - **日光暖橙**：米白画布、暖橙琥珀色核心主题节点、灰度连接线。
  - **仿电子墨水屏**：纸质背景底色、纯正黑墨节点文字、细铅笔灰色连线，无任何炫光。
  - **极客暗黑**：Lights-Out 纯黑底色、电光蓝主轴光晕、极客白文字。

#### 3. 全键盘极客操作交互机 (`src/hooks/useMindMapKeybindings.ts`)
- 无需鼠标，双手完全停留在键盘上完成高效头脑风暴：
  - `Tab`：选中当前节点，在其下方插入一个子主题（Child Node）并自动进入编辑状态。
  - `Enter`：插入同级兄弟主题（Sibling Node）。
  - `Shift + Tab`：提升当前节点层级（变为父级的兄弟）。
  - `Space`：快速切换当前分支展开/收起折叠状态。
  - `Ctrl + ↑ / ↓`：调整同级节点的相对前后位置。
  - `Ctrl + ← / →`：在父子层级之间平滑穿梭导航。
  - `F2` 或双击：就地激活文字行内修改框。
  - `Delete` / `Backspace`：删除选中节点（若包含子节点则弹出二次防护确认）。

#### 4. 高保真导出与跨平台分发
- **3× Retina 超清 PNG**：根据脑图当前逻辑包围盒自动拓展安全边距，以超高 DPI 导出全景图片。
- **纯矢量 SVG 导出**：无损矢量路径，导入 Figma、Illustrator 或 PPT 自由无损放大。
- **OPML / Markdown 大纲导出**：与 XMind、FreeMind、OmniOutliner 完美兼容。

### 模块 2：本地优先无限空间可视化白板（Infinite Canvas / Whiteboard） 🟢 `[⚡ GPU 图形渲染加速]`

#### 1. 开放 `.canvas` 标准格式与原子落盘 (`src/services/canvas-storage.ts`)
- 采用完全透明、开放的 JSON 文件结构，扩展名为 `.canvas`（兼容 Obsidian Canvas 工业规范）：
  ```json
  {
    "nodes": [
      { "id": "node-1", "x": 100, "y": 200, "width": 360, "height": 220, "type": "text", "text": "## 核心架构设计\n内嵌 Markdown 编辑" },
      { "id": "node-2", "x": 560, "y": 200, "width": 400, "height": 300, "type": "file", "file": "docs/architecture.md" },
      { "id": "node-3", "x": 100, "y": 480, "width": 240, "height": 160, "type": "sticky", "color": "amber", "text": "💡 灵感待办：重构 I/O" }
    ],
    "edges": [
      { "id": "edge-1", "fromNode": "node-1", "fromSide": "right", "toNode": "node-2", "toSide": "left", "label": "依赖并调用", "style": "curved" }
    ]
  }
  ```
- 接入应用已有的原子事务落盘管道（Temp + Fsync + Rename），保证在异常断电或强退时画布数据绝对完整。

#### 2. 无界空间视口与摄像机控制系统 (`src/components/canvas/CanvasViewport.tsx`)
- **空间坐标系矩阵变换**：
  - 维护摄像机视角状态 `{ x: number, y: number, zoom: number }`，缩放范围 `0.1× ~ 10.0×`。
  - 支持鼠标滚轮缩放与平移平滑切换、触控板双指缩放/平移惯性滑动。
  - 空格键按住时激活抓手工具（Hand Tool），随心拖拽漫游。
- **网格背景**：支持点阵（Dot Matrix）与工程方格（Grid），随缩放比例自动执行两级 LOD 细分淡入淡出。

#### 3. 多形态知识卡片组件族 (`src/components/canvas/nodes/`)
- **`CanvasTextNode.tsx`（Markdown 便签卡片）**：
  - 具备完整的 Markdown 预览与轻量就地编辑能力，支持粗体、代码块、列表与 KaTeX 公式。
- **`CanvasFilePortalNode.tsx`（知识库文档传送门卡片）**：
  - 支持从左侧文件树直接拖入任意 `.md` 章节。卡片内呈现文档实时标题与正文摘要，点击直接在主视图或分屏打开完整文档。
- **`CanvasStickyNode.tsx`（彩色便签卡片）**：
  - 提供暖黄、薄荷绿、天空蓝、薰衣草紫等多种优雅便签底色，适合头脑风暴与快速灵感碰撞。
- **`CanvasMediaNode.tsx`（媒体与架构图卡片）**：
  - 拖拽本地 PNG/JPG/SVG/WebP 图片直显，支持嵌入实时渲染的 Mermaid 架构图。
- **`CanvasFrameNode.tsx`（画框容器分组）**：
  - 框选一组节点放入画框，支持给画框命名（如“前端渲染层”），拖动画框整体移动内部所有子卡片。

#### 4. 智能磁吸矢量连线与语义关系引擎 (`src/components/canvas/CanvasEdgeRenderer.tsx`)
- **智能锚点吸附**：鼠标移动到任意卡片边缘时，自动浮现 4 个中点或 8 个网格锚点，拖拽出引线自动磁吸至目标卡片锚点。
- **连线形态**：
  - **贝塞尔曲线（Curved）**：柔和优雅，适合发散型思维关联。
  - **正交折线（Orthogonal）**：直角寻路，适合架构图与流程推导。
  - **直线（Straight）**：短距精准关联。
- **语义文字标注（Semantic Edge Labels）**：
  - 双击连线中间，就地呼出文字标签框，输入关联关系（如“推导自”、“依赖”、“同义词”、“反例”），箭头支持单向、双向与无箭头。

#### 5. 60 FPS 极速运行与视口裁剪剔除（Frustum Culling）
- **性能痛点**：当白板中存在数百张 Markdown 卡片和海量连线时，全量渲染会导致 DOM 重排雪崩与显存膨胀。
- **优化方案**：
  1. **空间包围盒四叉树（Quadtree Spatial Index）**：毫秒级过滤出当前视口内（加 20% 安全边距）可见的卡片与连线。
  2. **视口外元素休眠（Off-screen Virtualization）**：超出视野范围的节点完全剔除出激活渲染队列，仅在内存中保留几何信息。
  3. **复杂卡片静态位图快照（LOD Caching）**：当缩放比例 `< 0.4×` 时，卡片内部复杂的富文本自动降级为预渲染位图缩略图，确保 5,000+ 卡片在 4K 大屏下依然满帧 **60 FPS** 飞速漫游。

### 模块 3：思维导图与无限白板同双链网络的深度融合

1. **节点与卡片内的全功能双链解析**：
   - 无论在思维导图的标题节点中，还是在白板的 Markdown 便签与连线标签中，键入 `[[文档]]` 均可呼出智能补全。
   - 鼠标悬停即刻弹出 `LinkHoverPopover` 微光快照预览，保持知识上下文完整连续。
2. **双链拓扑一键可视化转白板（Convert Graph to Canvas）**：
   - 在图谱视图或反向链接面板中，提供「🌟 将当前关联网投射至新白板」操作，自动将选中的中心文档及其引用关系排布为白板卡片与连线，实现从无形网状关联到有形空间规划的无缝跨越。

### 模块 4：100% 本地离线混合搜索引擎与全能命令中心

#### 1. 混合检索双引擎架构 (`src/services/search/`)
- **字面精确检索（BM25 · SQLite FTS5）**：
  - 纯 CPU 驱动，构建本地分词全文索引，毫秒级召回精准代码段、特定参数与行号。
- **本地轻量向量检索（Embedding · ONNX）**：
  - 采用轻量高性能中文/英文 Embedding 模型（`bge-small-zh-v1.5` / `all-MiniLM-L6-v2`，~45MB）。
  - 支持 WebGPU 加速（吞吐 > 1,000 段落/秒），无 GPU 时采用 WASM SIMD 后台空闲增量构建。
- **RRF 混合重排（Reciprocal Rank Fusion）**：
  - 综合字面匹配与语义相似度评分，彻底解决“只记得意思想不起精确词汇”的搜索痛点。

#### 2. 全能命令中心（Command Palette · `Ctrl + K` / `Ctrl + P`）
- 统一的高质感磨砂悬浮浮层：
  - `?`：列出快捷键与功能向导。
  - `@`：按文件名或小节快速跳转。
  - `#`：按知识标签聚类检索。
  - `>`：执行系统级动作（开启思维导图视图、新建无限白板、导出 PDF、切换主题等）。

## 🧪 五、 质量保证与性能基准测试

1. **单元测试与集成测试 (`vitest`)**：
   - `mindmap-ast.test.ts`：验证万行复杂 Markdown 转换为脑图节点的准确性，验证脑图拖拽调序后回写 Markdown 的零破坏与准确性。
   - `canvas-storage.test.ts`：验证 `.canvas` 格式规范的解析、序列化与异常 JSON 容灾自愈。
   - `culling-algorithm.test.ts`：验证视口裁剪算法在大坐标系下相交判断的精确性。
2. **性能与渲染基准指标**：
   - **思维导图**：2,000+ 节点全量展开缩放平移帧率保持 **58 ~ 60 FPS**，AST 解析耗时 **< 5ms**。
   - **无限白板**：5,000+ 卡片与 3,000+ 矢量连线场景下，平移缩放渲染耗时 **< 16ms/帧（满帧 60 FPS）**，内存驻留增加 **< 60MB**。
   - **混合检索**：全库万篇笔记检索冷启动响应耗时 **< 50ms**。
